NEAR 3.53 -1.40%

NEAR AI breach post-mortem, ~100 users exposed

NEAR AI published a security report Nov 9 on a breach that began Nov 8, when an attacker exploited a remote code execution flaw in SGLang, the open-source inference engine on NEAR AI's servers. The attacker downloaded account information for about 100 users (emails, names, and for some, subscription plan and balance details) from a system tied to the discontinued Private Chat service, and accessed 18 agents running on an older version of NEAR AI Agents; two Cloud customers had API keys exposed via logs. NEAR AI suspended Cloud inference, revoked sessions and credentials, took Private Chat offline, patched SGLang, and has restored the service. The NEAR Protocol blockchain and other ecosystem services were unaffected.
